# Nomenclature — scope stub

**Scope:** Two-tier vocabulary discipline: neutral ecosystem terms (`PoW`/`PoS`, chain ID,
EIP/ECIP-NNNN) at the shared/framework level, network-specific fork/event names (`London`,
`the Merge`, `Osaka`, `Olympia`) as family-local instance labels only — the anti-conflation
rule one layer above `scala3/`'s `Eth*`/`Etc*` symbol-naming rule.

**Owning specialist:** cross-cutting; `forge` (PoW) and `beacon` (PoS) co-check
network-family-local labels for accuracy, since this is exactly the kind of thing PARITY-02
(`.claude/sprints/QUEUE.md`) warns is easy to get backwards (fork-named objects not
reliably named after the network that actually uses them).

**Authority:** ECIPs/EIPs terminology under `.claude/repo-references/`; in-house
`Eth*`/`Etc*` symbol convention.

**Status:** not yet authored. `.agents/protocols/code-style/nomenclature.md` currently
carries this content as a protocol; migrating it here is a follow-on pass (see
`README.md`'s per-domain migration plan).
