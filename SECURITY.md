# Security Policy

If you believe you have found a security vulnerability in fukuii, we encourage
you to report it to us as soon as possible. We ask that you do not publicly
disclose any details of the vulnerability until we have had an opportunity to
investigate and address it.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting to disclose security
issues: [Report a vulnerability](https://github.com/chippr-robotics/fukuii/security/advisories/new).
This opens a private draft security advisory visible only to the repository's
maintainers and GitHub — it is not a public issue, and no separate setup is
required on your end.

Please include as much detail as possible: a description of the issue,
reproduction steps, affected version/commit, and any known active exploitation.

We will acknowledge your report within 5 business days and keep you informed
throughout the investigation and resolution process. We do not currently
operate a bug-bounty program.

## Scope

This policy covers vulnerabilities in fukuii's own code (consensus, networking,
JSON-RPC, storage). Vulnerabilities in third-party dependencies should be
reported upstream as well as to us if fukuii's usage is directly exploitable.
