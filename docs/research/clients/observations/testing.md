## Best-practice synthesis

**DEFAULT (what fukuii's test infra should be built on):**
- **JSON-fixture → parameterized-test engine** consuming `ethereum/tests` + EEST — the universal conformance shape (geth reflective walk / besu codegen / reth trait-split are three renderings of the same idea). fukuii's ScalaTest consumer already occupies this slot; borrow reth's `Case`/`Suite` two-trait split so new fixture formats (EEST, hive) reuse one walk/parallelize/report scaffold.
- **Expected-failure-WITH-REASON skip taxonomy** — replace every bare `ignore`/`pending`/`-- SKIP` of a failing consensus fixture with an *asserted, reasoned expected-fail* entry (erigon's `Fails(pattern,reason)`), so a regression can't hide and a re-passing fixture flips loudly. **Scope skips PER-NETWORK** — a fork-choice fixture that is "inconclusive post-merge" (besu's `UncleFromSideChain_Merge` ignore) is still valid for ETC/PoW; a global skip would wrongly drop ETC coverage. Assert a nonzero fixture count so a missing submodule fails loudly (geth's silent `t.Skip`-the-whole-suite is the anti-pattern to avoid).
- **Fork identity carried in the test name** (besu's `ExecutionSpec*_prague_eip7702_*` generated class names) so **ETC-Olympia and ETH-Osaka fixtures are independently selectable** (`--tests "*_olympia_*"` vs `"*_osaka_*"`) with no runtime filter — directly serving fukuii's PoW-vs-PoS dual-family conformance.
- **Content-hash-pinned fixture manifest + failure-budget shards** (erigon's `test-fixtures.json` sha256 + `eest-spec-shards.yml` `max-allowed-failures`) to make fixture provenance and the "how many known-failing is acceptable" line explicit and reviewable.
- **In-tree hive adapter + suites** — fukuii already exceeds every peer (12 suites vs besu's zero in-repo files). Keep it.

**OPTIONAL (menu, by role):**
- **Acceptance-test cluster DSL** (besu) — the **Batch-7 private-network multi-node case**: boot N real nodes, action/condition fluent vocabulary, `verify` across the cluster. Adopt when the consortium/enterprise story needs end-to-end validation.
- **Property-based tests** (reth `proptest` → fukuii **ScalaCheck**) — trie-root equivalence, RLP round-trip, codec `Arbitrary` derivation, each with a fixed seed. High value, incremental, sits beside the fixture consumer.
- **ETC-fork fixture generation** (core-geth `mgen` analog) — fukuii must *generate* its own Olympia-era ECIP vectors; the frozen 2025 `etclabscore/tests` snapshot stops at Mystique.
