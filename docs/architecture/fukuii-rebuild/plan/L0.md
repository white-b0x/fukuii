_The foundation layer: value types, hashing/signing, RLP, KZG/BLS. **Built first, before this plan
existed** — this doc is the plan reconstructed against the Systemic Review + the review that followed, and
it is the worked example of the per-layer template (`plan/README.md`). It is brought to the same bar as
L1–L10 (`REVIEW.md` §7): every governing SR verdict quoted, all six clients mined per-concern, every
`optimizations.md` L0 row homed, every L0 downward constraint (`requirements.md`) satisfied, deferrals
scheduled with tests. The as-built record is [`../implementation-reports/01-L0-foundation.md`](../implementation-reports/01-L0-foundation.md); the gate that caught what
a plan-first approach should have pre-empted is [`../implementation-reports/L0-review.md`](../implementation-reports/L0-review.md). Every later layer
plans first for exactly that reason. Live build-status is the `../README.md` index only — never restated
here (docs-future-proof rule)._

## 1. Scope & modules

Four L0 modules under `com.chipprbots.fukuii.*`, all near-leaves; the only internal edges are
`crypto → bytes` and `rlp → bytes` (an upward edge is a compile error — the structural fix for the old
13-package cycle). `common` is a true leaf with **no** `domain` edge:

- **`bytes`** — fixed-width value types (`Address`, `Hash`/`Bytes32`, `UInt256` with full 256-bit modular
  arithmetic), hex, **unsigned** byte ordering. No deps. This is where the reference field puts value types
  (geth `[N]byte`, besu Tuweni `BytesHolder`) — old fukuii diverged (raw `ByteString`, value types pushed
  up into `domain`).
- **`common`** — genuinely generic, dependency-light utils (the logging facade — R10/F2). A true leaf, NO
  `domain` dependency (breaks the old `domain↔utils` cycle). Grows only when a concrete consumer needs it.
- **`crypto`** → `bytes` — keccak-256, secp256k1 ECDSA (sign/recover/address-derivation), **secp256r1
  ECDSA verify** (`0x0100` P256VERIFY primitive, pure-BouncyCastle), alt-bn128 (BN128, zksnark), ECIES,
  KZG (`0x0a` primitive), BLS12-381 (EIP-2537 primitive), **Blake2b F compression** (`0x09` BLAKE2F
  primitive), and the **`constantTimeEquals` security primitive** (R11).
- **`rlp`** → `bytes` — typeclass/`derives` codecs, the byte engine, base + value-type instances.

**The non-flat leaf shape is deliberate and mirrored from besu.** Anything needing the `rlp` typeclasses,
the ckzg JNI dep, or `domain`/`jsonrpc` (`ECDSASignatureImplicits`, `UInt256RLPImplicits`, `KzgCellProofs`)
lives one layer up in the composition module, not in these leaves — the same `{root glue} → {rlp, crypto}
→ bytes` layering besu documents for `datatypes → {rlp,crypto}`.

## 2. SR slots & verdicts

Governed by [`observations/primitives.md`](../../../research/clients/observations/primitives.md) and
[`observations/build-deps.md`](../../../research/clients/observations/build-deps.md); SR alignment finding
**SR-10** (primitives = the first Phase-3 subsystem). Verdicts honored (quoted, cited):

- **DEFAULT: fixed-width wrapper/opaque value types at the primitives level** — "opaque types over
  `Array[Byte]`/`ByteString`, type-distinct so `Wei` can't silently mix with a raw `UInt256`"
  (`primitives.md` best-practice synthesis). geth `Hash [32]byte`/`Address [20]byte`, besu Tuweni
  `BytesHolder`/`BaseUInt256Value`. Old fukuii's raw-`ByteString` slot = "the wrapper DEFAULT is unmet at
  this slot" (`primitives.md` comparison row) — the rebuild moves them down.
- **DEFAULT: derive-macro / typeclass-derived RLP codecs** — "compile-time-resolved, per-type, explicit,
  no reflection walk … Prefer it over hand-rolled encoders" (`primitives.md`). reth alloy
  `#[derive(RlpEncodable)]` + nethermind per-type registry → Scala 3 `given RLPCodec[T]` / `derives
  RLPCodec`.
- **DEFAULT (JVM structural analog): besu streaming-cursor `RLPInput`/`RLPOutput`** as the reader/writer
  plumbing shape under the typeclass — "the shape to mirror for the reader/writer plumbing under the
  typeclass … not a competing codec-authoring model" (`primitives.md`).
- **DEFAULT: fixed-width `UInt256` arithmetic belongs at the primitives level** — arithmetic on the number
  type is universal (`holiman/uint256`, Tuweni `UInt256`); `UInt256`'s 256-bit modular arithmetic belongs
  in `bytes` (L0), not deferred to `domain`.
- **OPTIONAL(role): dual native+pure crypto backend behind one API** — "native fast-path →
  validator/archival/mining-pool throughput … pure fallback → enterprise single-binary portability"
  (`primitives.md`). Four of six clients ship it (geth/core-geth/besu/erigon). Adopted as a **STRUCTURAL
  seam now, OPTIONAL(role) occupancy** (§7).
- **OPTIONAL(role: tooling-family): shared-primitives-library seam** — for fukuii "the analog is
  module/artifact boundaries (already three sbt sub-modules)" (`primitives.md`). Satisfied by the
  `bytes`/`crypto`/`rlp` module split; publishing is a later product-family lever, not an L0 build task.
- **OBSOLETE(for JVM port): nethermind zero-alloc value structs** — "`ValueHash256` as a SIMD
  `Vector256<byte>` … does NOT port to the JVM. Scala's ceiling is erasing the *wrapper* object via opaque
  types; it cannot inline 32 bytes into a containing object" (`primitives.md` NOTE). Consciously avoided;
  we chase erigon's *pooling/benchmark* discipline (which transfers) instead.
- **DEFAULT (build-deps): single-version-source + checksummed supply-chain gate** — governs *setup*, not
  L0 code, but L0's three modules import versions from `project/Dependencies.scala` versionlessly and never
  inline a version in a submodule `build.sbt` (`build-deps.md`; besu `:platform` BOM ≙ `Dependencies.scala`;
  the `july-fourth` `bouncycastle 1.84 ×2` / `json4s 4.0.7 ×2` duplicate literals are the discipline breach to
  avoid). sentinel owns the gate (R6/R11).

## 4. besu structural mirror

- **secp256k1** → besu `AbstractSECP256`/`SECP256K1` (BouncyCastle `ECDSASigner` + `HMacDSAKCalculator`
  RFC-6979, `normaliseSignature`/`decompressKey`/`recoverFromSignature`, the `q.isInfinity()` reject-guard
  — the B-ECDSA-1 infinity guard). **Anti-pattern to avoid:** `SignatureAlgorithmFactory`
  (`crypto/algorithms/.../SignatureAlgorithmFactory.java:32-44` — `private static SignatureAlgorithm
  instance = DEFAULT_INSTANCE;` + `public static void switchInstance(ecCurve)`) is a **JVM-global mutable
  static** curve/backend selection. Under R2 (concurrent multi-instance, single-binary) that breaks
  per-instance isolation — one instance's `switchInstance` would flip the curve for every other network in
  the process. fukuii's L0 selects backend/curve **per-instance or per-call**, never through a JVM-global
  static (§7 seam).
- **KZG** → `KZGPointEvalPrecompiledContract` (`/kzg-trusted-setups/mainnet.txt`, `Precompute=0`);
  trusted-setup provenance is locked (B-KZG-1).
- **RLP** → `RLPInput`/`RLPOutput` cursor as the plumbing shape under the typeclass (accumulate-then-
  single-walk encoder for nested lists) — explicitly *not* a competing codec-authoring model.
- **constant-time** → BouncyCastle `Arrays.constantTimeAreEqual`, called at exactly the sites besu calls it
  (auth/MAC/secret equality), and plain `Arrays.equals` at non-secret integrity sites (besu's per-frame
  MAC `Framer.java:321`) — the *conditional* standard, not a blanket conversion
  (`best-practices/evm-clients/constant-time-comparison.md`).
- **value types** → besu `datatypes` (Tuweni-backed).

## 5. Scala 3 idiom targets

Grounded in `best-practices/scala/type-safety` + the `scala3`/`docs.scala-lang` reference repos, not
asserted:

- **Opaque types** — `Address`/`Hash` = `ByteString`, `UInt256` = `BigInt` — type-distinct at compile
  time, zero-cost at runtime (the JVM caveat: opaque types erase the *wrapper*, not the 32-byte backing
  array; do **not** attempt nethermind inline structs).
- **`extension`/`given`, never `implicit class`/`implicit def`** — the `july-fourth` `FiniteField.Ops` (an
  `implicit class`) and `RLPImplicitConversions` (`implicit def`) are Scala-2-era holdovers to rewrite as
  `extension`/`given`.
- **`trait RLPCodec[T] extends RLPEncoder[T], RLPDecoder[T]` with `inline def derived`** — a real class
  type (the old intersection-alias `type RLPCodec[T] = RLPEncoder[T] & RLPDecoder[T]` could never be a
  `derives` target, which is why the `july-fourth` `case class … derives RLPCodec` clause did not compile). Backed
  by `Mirror.ProductOf` + a recursive `TupleRLPCodec[H *: T]` field-tuple typeclass (`rlp/codec.scala`);
  the base `derived` is a straight field-list (product ⇄ `RLPList` of its fields in declaration order).
  Trailing-optional omission — geth's `rlp:"optional"`/`"tail"` struct tags — is a **hand-written `given`
  per consuming type** (the domain fork-variant header/body), not a `DerivationPolicy` object: `rlp`
  exposes no such object.
- **One `given RLPCodec[T]` per type** (the `july-fourth` declared a *triple* per base type — the `&` intersection
  + separate `RLPEncoder` + `RLPDecoder`; single-given collapses the implicit-scope noise).
- **Multiple named `given`s per type where two wire forms exist** — see the named-variant registry (§7).
- **Top-level** `encode`/`decode`/`decodeStrict`; braceless syntax; `enum` where a closed set applies.

Idiom lens verdict at the gate: **GREEN, "cleanest layer reviewed."**

## 6. Improvements over old fukuii (each an `july-fourth` gap closed)

From `.local/docs/research/clients/fukuii/primitives.md`, each a floor:

- **Value types at the primitives layer** (were in `domain`; `bytes/` exposed only raw
  `ByteString`/`Array[Byte]`).
- **Unsigned lexicographic byte ordering** — the old signed compare sorted `0xff` before `0x01`, a latent
  trie/access-list consensus footgun; closed with `& 0xff` (F-RLP ordering).
- **`derives RLPCodec` that actually compiles and is wired** — the `july-fourth` `Mirror` derivation existed
  (`RLPDerivation.scala`) but was unwired (0 call sites) and `derives RLPCodec` did not compile (bare
  `type` alias, no `derived` companion method); production used ~50 hand-rolled codecs. The DEFAULT the
  codebase already *owned* but diverged from.
- **One `given RLPCodec[T]` per type** (was a triple per base type — `RLPImplicits.scala:27-29`).
- **Strict decode from line one** (`decodeStrict`/`rawDecodeStrict` — the RLP-DECODE-01/02 trailing-bytes
  guard).
- **Hex odd-length + non-hex rejection** (`july-fourth` `Hex.decode` had no odd-length guard).
- **`common` minimal** — not the old grab-bag `utils` that carried a `domain` back-edge.
- **`constantTimeEquals` exposed as a callable L0 symbol (build-gate, RX-L0-16)** — the `july-fourth` keystore MAC
  compares with plain `==` (a real timing finding). L0 now exposes a top-level `def constantTimeEquals`
  (`crypto/ConstantTime.scala`) over BouncyCastle `Arrays.constantTimeAreEqual`, with the ECIES MAC site
  re-pointed through it, and it is the lint target its consumers — **L6 ECIES tag / L8 keystore MAC / L9
  JWT** (no L1 site) — call (§7, R11). _(Built in the L0 close-out — `ConstantTime.scala`, ECIES
  re-pointed; see the README index + `01-L0-foundation.md` §17.)_
- **Named-as-closed scratch/noise** — `TestScala3.scala` (a "verify Scala 3 syntax works" object with no
  callers, shipped in `rlp/src/main` of a consensus-adjacent module) is deleted; the triple-given noise is
  collapsed (§7 `july-fourth` cleanups).

## 8. Cross-cutting requirements carried (L0 downward constraints)

Every `requirements.md` matrix cell where a requirement bites L0 — the completeness test (`REVIEW.md` §5b):

- **R1 (multi-network) — neutral types.** Value types + crypto carry **no** network identity;
  ordering/canonical ops are network-agnostic. A baked-in network assumption at L0 poisons everything above
  and forces `isEtc()` branches at L5. DoD grep: no chain-id/fork/network symbol in any `bytes`/`crypto`/
  `rlp` type. *(This is what lets L5's `NetworkFamily` be a thin seam — the operator's structural spine.)*
- **R2 (multi-instance) — no global singletons / mutable statics.** The per-instance backend/curve seam
  (§7) is the L0 expression: no JVM-wide crypto state (besu `SignatureAlgorithmFactory` static is the named
  counter-example). DoD grep: no `object … { var … }` holding crypto/backend state.
- **R4 (byte-exactness) — ✔ full.** `crypto` + `rlp` are consensus (forge/beacon gate). Every value
  validated against the verified reference map (built from the per-concern authority *first*, then diffed),
  never against current code. Reference vectors in §9.
- **R5 (Typed/effect) — `IO` at the module edge, pure core.** L0 is overwhelmingly pure (no actors); the
  effect discipline that bites is: side-effecting entry points (key generation, trusted-setup load) return
  `IO` rather than running effects eagerly, so L2's `DataSource` and the actor layers above compose them —
  no `unsafeRunSync` leaks downward (TL1/TL2). Pure sign/hash/encode stay effect-free total functions.
- **R6 (born-modern) — Scala 3 idiom + successor deps from line one** (§5); versions sourced only from
  `project/Dependencies.scala` (no inline submodule literals); supply-chain gate is sentinel-owned.
- **R10 (observability) — structured logging in `common`.** The `common` logging facade is SLF4J-based,
  secret-free by construction (no key/seed material in log lines) — the L0 slice of R10/F2.
- **R11 (security) — `constantTimeEquals` primitive + sign-side low-S canonicalization.** The primitive
  (§7) plus L0's **sign-side low-S canonicalization and recover-side curve-order check** (R4 byte-exact,
  forge/beacon-gated). **The incoming-signature range gate** (r,s ∈ [1, N), s ≤ N/2 — geth
  `ValidateSignatureValues`) is **L1's, not L0's** (RX-L0-11): L0 canonicalizes what it *signs* and checks
  curve order on *recover*; L1 validates *inbound* tx signature values. The pure crypto path must re-add
  low-S if a native path ever omits it.

R3/R7/R8/R9 do not bite L0 (they land at L2+); stated here so a reader confirms the empty cells are
intentional, not overlooked.

## 9. Exit DoD (GREEN bar) + risks & consensus-critical flags

**Gate lenses (all four, none the builder; multi-pass per `REVIEW.md` §6b — advance only on a clean pass
following ≥2 found-and-fixed):** (a) correctness/byte-alignment vs go-ethereum + core-geth; (b) besu
JVM-implementation lens; (c) Scala 3 idiom (mithril); (d) test quality + coverage vs reference vectors
(eye, runs the suites) + the requirements/ledger check (every §7 row and §8 constraint adopted / scheduled
/ consciously deferred).

**Reference vectors that must pass:** canonical `rlptest.json` + `invalidRLPTest.json`; secp256k1
sign/recover KATs; keccak vectors; EIP-2537 positive + subgroup-rejection KATs (9/9 ops); EIP-4844
`blobToKzgCommitment` KAT + trusted-setup provenance lock; alt-bn128 on-curve-off-subgroup rejection;
constant-time-equal KAT (equal / unequal / length-mismatch); dual-backend differential KAT (once a native
path is added).

**Consensus-critical flags — `crypto` + `rlp` are consensus (byte-exact, forge/beacon gate).** Traps this
layer proved real, kept as the standing risk register:

- **alt-bn128 G2 subgroup check** (F-BN-1 — a chain-split; G2 needs the order-`r` check, G1 doesn't,
  cofactor 1). Remediated; the KAT that proves it (on-curve-off-subgroup rejection) is a permanent gate.
- **Non-canonical RLP acceptance** (F-RLP-1 — a network-partition vector). Remediated via
  `rawDecodeStrict`; `invalidRLPTest.json` is a permanent gate.
- **JVM-integer RLP-offset overflow** (J-RLP-1 — `Int`→`Long`; invisible to a Go comparison, caught only
  by the besu JVM lens). Remediated. fukuii caps the length-of-length at **4 bytes**
  (`MaxLengthOfLength = Integer.BYTES`), a *deliberate JVM-index tightening* stricter than geth's 8-byte
  `readSize` (`rlp/raw.go:387-416`) — **do not widen it to 8 to "match geth."** The cap is behaviorally
  equivalent to geth on every buffer-realizable input: no `Array[Byte]` can hold ≥2³¹ bytes, so a 5–8-byte
  length declares a payload no real buffer can satisfy, which geth *also* rejects (via `ErrValueTooLarge`,
  contentsize > len(buf)). The cap therefore never rejects a valid mainnet item; it rejects adversarial
  oversize headers one step earlier.
- **Signed-`Byte` ordering footgun** (correctly avoided with `& 0xff` — the unsigned-ordering fix).
- **JVM-backend divergence** (B-BLS-1 — legacy `LibEthPairings` vs gnark; B-ECDSA-1 infinity guard;
  B-KZG-1 trusted-setup). Rule: pick the same native backend besu validates, or prove byte-equivalence
  with positive + rejection KATs. This is exactly the correctness surface the dual-backend seam (§7)
  formalizes — both paths must be output-identical.

The `bytes`/`crypto` value layer, keccak, secp256k1, and the native wrappers are byte-exact and
trustworthy on honest input; the gate exists because two adversarially-reachable divergences (F-BN-1,
F-RLP-1) shipped as "done" before it ran — the reason every later layer plans first (`plan/README.md`).

## Agentic alignment (per-layer lifecycle step 5)

The L0 specialist charters are **forge** (PoW consensus crypto — alt-bn128, keccak-PoW, ECDSA byte-exactness,
the consensus gate on `crypto`/`rlp`), **mithril** (Scala 3 idiom — opaque types, `given`/`extension`,
`derives`), and **eye** (validation — runs the KAT/`rlptest` suites, the alloc-benchmark harness once
landed). **beacon** co-gates any ETH-family primitive touch (KZG/BLS/4844). The storage (`storage-rocksdb`)
and consensus-change (`consensus-change-protocol`) protocols do **not** touch L0 — L0 has no DataSource and
no fork-dispatch; a charter that points those at `bytes`/`crypto`/`rlp` is stale. Charters must reference
the real `modules/{bytes,crypto,rlp,common}/` tree, not dead `src/main/scala/com/chipprbots/ethereum/…`
paths (the L0 dead-`src/`-charter miss). warden owns the mechanics.

## Layer boundaries (what lives elsewhere, and why)

- EVM-opcode gas-metered `UInt256` semantics (EXP gas, SIGNEXTEND) → `evm` (L3). `Wei`/semantic wrappers →
  `domain` (L1).
- KZG/BLS/alt-bn128 *precompile wrappers* (gas/decode/dispatch) → `evm` (L3), calling down into `crypto`.
- RLP trailing-optional-omission policy + typed-tx (EIP-2718) aggregation → `domain` (L1) (the fork-variant
  header + tx types are the consumers). The **named-variant registry seam** (§7) is *not* built at L0 — it is
  an **L1-kickoff prerequisite** (deferred-to-first-consumer), built as the first step of the L1 blob codecs
  by its first occupant (the blob consensus-vs-network wrapper).
- `constantTimeEquals` is *exposed* at L0; its consumers (keystore MAC, ECIES tag, JWT/auth gate) are
  L6/L8/L9.
- The dual-backend seam is *designed* at L0; a native fast-path *occupancy* is scheduled OPTIONAL(role) with
  a differential KAT.
- `common` grows only on concrete demand — never speculatively.
